# Hi, I'm Daniel Fridman

I'm an Embedded Systems Engineer interested in low-level programming, real-time systems, embedded Linux, and edge AI.

I have more than five years of professional experience in embedded software, hardware bring-up, communication protocols, and debugging on real devices. 

I enjoy understanding systems from registers and startup code all the way to RTOS applications, networking, and complete hardware-software architectures.
